🌿 EcoAmigos
Pequenos passos, um mundo gigante e feliz! 🌎💚

O EcoAmigos é um site educativo e interativo criado para incentivar práticas sustentáveis de uma forma leve, divertida e acessível.

A proposta é mostrar que cuidar do planeta pode fazer parte do dia a dia através de pequenas atitudes, como economizar água, reduzir o uso de plástico e consumir energia de maneira consciente.

✨ Funcionalidades
🌿 Página inicial: apresentação do projeto e chamada para começar a aventura ecológica.
🐢 Missões Ecológicas: dicas e ações sustentáveis relacionadas ao oceano, energia e água.
💡 Cantinho das Ideias Mágicas: sistema interativo que sorteia diferentes dicas ecológicas.
🎮 Termômetro Ecológico: pequeno quiz que calcula uma pontuação com base no uso de carro/moto e de plásticos descartáveis.
📱 Design responsivo: estrutura preparada para diferentes tamanhos de tela.
🎨 Interface amigável: utilização de cores, emojis e elementos visuais para criar uma experiência descontraída.
🧮 Como funciona o Termômetro Ecológico?
O usuário informa:

Quantas horas por semana utiliza carro ou moto.
Quantos copos ou itens plásticos descartáveis utiliza por dia.
A aplicação calcula uma pontuação através da fórmula:

pontuação = (horas de transporte × 2,5) + (plásticos por dia × 1,8)

O resultado é classificado em três níveis:

🌟 Menos de 15 pontos: Guardião da Natureza.
💛 De 15 a 39,99 pontos: usuário no caminho certo.
🌱 40 pontos ou mais: oportunidade para desenvolver novos hábitos sustentáveis.
Observação: essa pontuação é apenas uma brincadeira educativa e não representa um cálculo científico real de pegada de carbono.

🚀 Como executar
Não é necessário instalar nenhuma dependência.

1. Clone ou baixe o projeto
git clone <URL_DO_REPOSITORIO>

2. Entre na pasta
cd EcoAmigos

3. Abra o projeto
Abra o arquivo index.html diretamente no navegador.

Também é possível utilizar uma extensão como Live Server no Visual Studio Code para executar o projeto durante o desenvolvimento.
